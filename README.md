# Привет! Я Дмитрий 👋

## 🛠️ Мой технологический стек

* **Сore:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Методологии и стили:** БЭМ (BEM), Flexbox, CSS Grid, Адаптивная и резиновая верстка
* **Инструменты:** VS Code, Git / GitHub, Figma (пиксель в пиксель перенос макетов)

## 🚀 Мои принципы в работе

* 🚀 **Максимальная скорость:** Сайты без тяжелых фреймворков и библиотек загружаются мгновенно.
* 📐 **Чистая структура:** Валидный семантический код, в котором легко разобраться.
* 📱 **Адаптивность:** Корректное отображение на любых устройствах — от старых смартфонов до 4К мониторов.
* 🎨 **Внимание к деталям:** Точное соответствие дизайн-макету и плавные анимации.
